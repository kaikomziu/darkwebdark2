# DarkWebDark 2

ブラウザで遊ぶ、ネットサーフィン型ホラーゲームの続編です。

前作「[DarkWebDark](https://github.com/kaikomziu/darkwebdark)」で、ゆきは壁の中に消えました。
今回あなたが開くのは、ゆきの友だち **まい** のページ。最後の投稿は「ゆきの部屋、見てくる」。
それ以来更新はないのに、見るたびに **下書き** が増えていきます。

> ⚠️ 大きな音・突然の驚かし（ジャンプスケア）・点滅する表現があります。最初の画面と左下の ⚙ で「点滅・揺れを弱める」を設定できます。

## 遊び方

- `index.html` をブラウザで開けば始まります（サーバー不要）。
- 公開版（GitHub Pages）：`https://kaikomziu.github.io/darkwebdark2/`
  - Pages は **`gh-pages` ブランチ** から公開しています。更新したら `main` と同じ内容を `gh-pages` にもプッシュしてください（`git push origin main:gh-pages`）。
- スマホ・PC 両対応（タップ／クリック、画面幅 390px〜）。1周 40〜60分ほど。
- 各ページの最初に入口ボタンがあります（音を鳴らすためにタップが必要なため）。
- 進行状況はブラウザ（localStorage）に自動保存されます。最初からやり直すときは、クリア後のひびログにある「さいしょから」を押してください。
- 前作を同じブラウザ・同じサイト（`kaikomziu.github.io`）で遊んでいると、ゲームの中で前作の記録に反応します。

### RTAモード（1回クリアで解放）

- クリア後のひびログに「RTAモード」が出ます。「RTA開始」から、最深部でエンディングが決まるまでのタイムを計測します（画面右上にタイマー、2回押しで中断）。
- RTA中は文字送りなどの演出が少し速くなります。
- オンラインランキングは1人1件、自分の最速タイムだけが残ります。
  - **GitHub Pages 版**：Supabase に保存（ブラウザごとの匿名IDで1件）。
  - **claude.ai 公開ページ版**：外部と通信できないため、claude.ai の共有データベースに保存。

### Supabase の準備（最初の1回だけ）

共有プロジェクト `kifnzvktwbomxthzvvgy` に、DWD2 専用の表を作ります（前作の `dwd_rta_scores` を含め、ほかの表には触れません）。

1. Supabase ダッシュボードで `kifnzvktwbomxthzvvgy` を開く
2. 左メニュー **SQL Editor** → **New query**
3. `supabase/dwd2_rta.sql` の中身をすべて貼り付けて **Run**
4. テーブル `dwd2_rta_scores` と関数 `dwd2_submit_rta` ができていれば完了（何度実行しても壊れません）

- 閲覧はだれでも可能。直接の書き込みは不可で、登録は security definer 関数 `dwd2_submit_rta` からだけ受け付けます。
- 1人1件。自己ベストより速いときだけタイムを上書きします（1分〜3時間のタイムのみ）。
